📲 GaleríaK 틱톡 키트

매일 저녁 6시 37분(멕시코) 오늘의 카드뉴스(3~9장)가 틱톡 앱 받은편지함으로 자동 도착해요. 알림 열기 → 문구 확인 → 게시!

예비용: 직접 예약하는 방법 (자동 전송이 안 될 때)
  1. 아래 카드마다 📤 카드뉴스 공유/저장을 눌러 사진을 받아요.
  2. TikTok Studio 업로드에서 사진(여러 장)을 올리고, 📋 문구 복사한 걸 설명에 붙여 넣어요.
  3. 「예약(Schedule)」을 켜고 카드에 적힌 예약 시간을 넣어요.

휴대폰에서는 📤 카드뉴스 공유 → 틱톡을 고르면 바로 사진 게시물로 올라가요. 이 페이지는 매일 자동으로 새 10일 치로 바뀌어요(D1 = 가장 가까운 날).
