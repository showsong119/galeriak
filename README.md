# GaleríaK

Comunidad en español para fans de K-Beauty y K-Pop en México — https://galeriak.netlify.app

| Carpeta | Qué hay |
| --- | --- |
| `site/` | El sitio (un solo `index.html` con Supabase, Google/correo, PWA) que Netlify publica |
| `scripts/publish-deals.mjs` | Bot de ofertas de Amazon México (publica en `posts` con `needs_review`) |
| `deals/inbox/` | Candidatos de la curaduría diaria (`CURATOR.md`) |
| `.github/workflows/deals.yml` | Bot diario 9:07 CDMX y al llegar candidatos |

Configuración: `SETUP.md` · Operación: `OPS.md` · Pruebas: `npm test`.
